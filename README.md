# Nhịp Ngày — Trợ lý Lịch Công việc

Trang trưng bày song ngữ Việt–Trung cho Agent lập kế hoạch công việc hằng ngày.

## Nội dung
- Giới thiệu mục tiêu, quy trình, quy chuẩn và ranh giới năng lực.
- Bản demo tương tác dùng dữ liệu minh họa, không kết nối Google Keep, API, tài khoản hay dịch vụ bên ngoài.
- Nút `中文 / Tiếng Việt` đổi ngôn ngữ toàn trang.

## Đưa lên GitHub Pages
1. Tạo một repository GitHub mới ở chế độ Public.
2. Đưa `index.html` và `README.md` ở thư mục này vào thư mục gốc repository.
3. Trong Settings → Pages, chọn deploy từ nhánh `main`, thư mục `/ (root)`.
4. Đợi GitHub Pages hoàn tất và dùng URL được hiển thị tại trang Settings → Pages.

Thư mục này chỉ chứa bản web tĩnh đã chọn để công khai. Không tải toàn bộ thư mục dự án hoặc các tệp cá nhân khác lên repository.
